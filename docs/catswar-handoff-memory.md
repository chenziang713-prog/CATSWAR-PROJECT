## 每账号完整流程

1. 启动/唤醒雷电实例，等待 C.A.T.S. 加载；开屏广告或普通干扰页可用返回键关闭。
2. 在主页点击顶部帮派/多人图标入口（交接图 06/07 蓝圈位置）。主页中央轮播里的“帮派战”牌子不是可靠入口，不能按文字直接点击。
3. 进入帮派页面后点击顶部“城市之王”页签。
4. 等待“正在寻找对手帮派”；等待期间不点任何加入类文字。
5. 只在城战页面右下出现完整按钮“加入”时点击。主页“加入联赛”和宣传语“攻击！快加入他们！”都不是该按钮。
6. 配车确认页必须同时看到“记住！这个车库不会影响你的终极战车”等上下文，再点击右下“开始”。
7. 二次确认弹窗必须看到完整“开始战斗吧！”，点击该按钮；“新的回合已开始！”不是配车开始。
8. 进入六建筑页，账号完成一次加入。每账号固定最多 3 辆车，不能重复加入；用检查点记录 `joined`。

## 建筑与车辆规则

- 六建筑按教学标记 P1 → P6 逆时针优先；每次战斗结束都重新截图、重新识别，不能沿用旧坐标。
- 建筑旁车辆图标右侧的独立数字才是 `X`；需求车辆数 `Y = floor(X / 2) + 1`。
- `仓库1/仓库2` 中的编号、`+21`/`+30` 奖励、`X2` 倍率、主页资源/礼包/倒计时数字都不是 `X`。
- 蓝色表示我方，红色表示敌方；红方建筑优先夺回。建筑进度条蓝色超过一半表示该建筑阶段已得分，应切换建筑。
- 只选择可出战车辆。维修/阵亡车辆跳过；敌方目标车有上锁标志时跳过；点击目标后出现“该玩家目前正与其他玩家战斗中”忙碌弹窗时点该弹窗的“确定”，再换下一辆。
- 本账号车辆选择器在左侧，`1/2/3` 按钮按顺序对应本账号第 1/2/3 辆车；它不能和右侧敌方目标车辆网格混淆。

## 战斗两阶段状态机

建筑名称 → 攻击/防御页 → 点击攻击上方的红色攻击图标（第一阶段） → 必须重新截图复核 → 新页面左下角红色“攻击”按钮（第二阶段） → 右侧敌方车辆网格选择目标 → 观战页点击“点击观战” → 等待胜利/失败 → 只在结算页看到“胜利/失败”及“确定”时点确定 → 返回建筑页重新扫描。

红色攻击入口和左下攻击按钮是两个独立状态、两个独立点击；不能把“攻击”文字、红色图标、左下按钮合成一个 marker，也不能在未截图复核时连续盲点。

## 页面上下文与误判防线

- “加入”“开始”“攻击”“确定”必须完整词匹配，并同时满足页面位置和上下文。
- “正在进行攻击”不是攻击按钮；“加入联赛”不是城战加入；“攻击！快加入他们！”不是加入；“新的回合已开始！”不是配车开始。
- “确定”必须按上下文分类：忙碌弹窗、战斗结算、活动/战争战利品、系统错误不是同一类动作。活动、礼包、公告、排名、商店等普通干扰页可返回；退出确认必须点“否”。
- 对局进行中禁止返回键；普通干扰页可使用游戏左下返回或模拟器系统返回。每个返回动作前后都要截图确认。
- 所有 bbox 是截图归一化坐标，运行时按当前截图真实宽高换算；禁止使用旧机器绝对屏幕坐标。

## 多账号运行约束

- 默认最多并发 3 个账号；每账号独立 ADB、截图目录、状态机、日志和 checkpoint。
- 一个账号失败/暂停不能阻塞其他账号；脚本负责启动/唤醒实例但不关闭实例。
- 保存最近截图、OmniParser 原始结果、状态转移、动作、错误、已加入标志、战斗次数、跳过车辆及原因。
- 本轮完成条件：没有可用车辆或没有可继续的建筑目标；不能因为一次识别失败就假报完成。
